# 🚀 Руководство по развёртыванию на Vercel

## Быстрый старт

### Шаг 1: Подготовка аккаунта Vercel

1. Перейдите на [vercel.com](https://vercel.com)
2. Нажмите "Sign Up" (Регистрация)
3. Выберите "Continue with GitHub" (Продолжить с GitHub)
4. Авторизуйте Vercel для доступа к вашим репозиториям

### Шаг 2: Импорт проекта

1. На главной странице Vercel нажмите **"Add New..."** → **"Project"**
2. В списке репозиториев найдите `ctrl111/FlightDeals-front`
3. Нажмите **"Import"** рядом с репозиторием

### Шаг 3: Настройка проекта

Vercel автоматически определит настройки:

```
Framework Preset: Next.js
Build Command: npm run build
Output Directory: .next
Install Command: npm install
Development Command: npm run dev
```

**Не нужно ничего менять!** Просто нажмите **"Deploy"**

### Шаг 4: Ожидание развёртывания

- Процесс займёт 2-3 минуты
- Вы увидите логи сборки в реальном времени
- После завершения появится сообщение "Congratulations!"

### Шаг 5: Получение URL

После успешного развёртывания вы получите:
- **Production URL**: `https://flight-deals-front.vercel.app` (или похожий)
- Автоматический SSL-сертификат (HTTPS)
- Глобальный CDN для быстрой загрузки

## 🔄 Автоматическое развёртывание

После первого развёртывания:

- ✅ Каждый `git push` в ветку `main` автоматически развернёт новую версию
- ✅ Pull requests создают preview-развёртывания для тестирования
- ✅ Откат к предыдущей версии в один клик

## 🎯 Пользовательский домен (опционально)

### Добавление своего домена:

1. В панели Vercel перейдите в **Settings** → **Domains**
2. Нажмите **"Add"**
3. Введите ваш домен (например, `flightdeals.ru`)
4. Следуйте инструкциям для настройки DNS

### Настройка DNS:

Добавьте A-запись или CNAME в настройках вашего регистратора доменов:

```
Type: CNAME
Name: @
Value: cname.vercel-dns.com
```

## 📊 Мониторинг и аналитика

Vercel предоставляет:
- 📈 Аналитику посещений
- ⚡ Метрики производительности (Core Web Vitals)
- 🐛 Логи ошибок
- 📉 Использование ресурсов

Доступно в разделе **Analytics** панели управления.

## 🔧 Переменные окружения (если нужны)

Если в будущем понадобятся переменные окружения:

1. Перейдите в **Settings** → **Environment Variables**
2. Добавьте переменные:
   ```
   NEXT_PUBLIC_API_URL=https://api.example.com
   NEXT_PUBLIC_CHAIN_ID=1
   ```
3. Пересоберите проект

## 🚨 Устранение неполадок

### Ошибка сборки

Если сборка не удалась:

1. Проверьте логи сборки в Vercel
2. Убедитесь, что проект собирается локально: `npm run build`
3. Проверьте версию Node.js (должна быть 18+)

### Проблемы с отображением

1. Очистите кэш браузера (Ctrl+Shift+R)
2. Проверьте консоль браузера на ошибки (F12)
3. Убедитесь, что все зависимости установлены

### Медленная загрузка

- Vercel использует глобальный CDN
- Первая загрузка может быть медленнее
- Последующие загрузки будут быстрыми благодаря кэшированию
